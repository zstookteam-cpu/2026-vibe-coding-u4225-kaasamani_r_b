## Как запустить бота из Лаб. 1

Подробная инструкция — в [`lab1/README.md`](lab1/README.md). Коротко (macOS / Linux):

```bash
cd lab1
bash run.sh      # создаст окружение, поставит зависимости, спросит токен и запустит бота
```

Токен бота получают у [@BotFather](https://t.me/BotFather). В репозиторий токен не попадает:
он хранится в локальном файле `.env`, который указан в `.gitignore`.
