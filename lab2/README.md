# 📝 Бот-ассистент для задач — Лаб. 2 (интеграция с данными)

Telegram-бот на Python (`python-telegram-bot`) из Лаб. 1, к которому подключены внешние данные:

- **Публичный API Open-Meteo** (погода и геокодинг, ключ не нужен) — модуль `weather.py`;
- **SQLite** — поиск по задачам и выборка за неделю, настройки города пользователя;
- **Меню команд Telegram** — список команд появляется при вводе `/`.

## Быстрый запуск (macOS / Linux)

```bash
bash run.sh
```

Скрипт создаст виртуальное окружение, установит зависимости, спросит токен бота (сохранит его в `.env`) и запустит бота.

> ⚠️ Одновременно может работать **только один** экземпляр бота с одним токеном.
> Если запущен бот из Лаб. 1 — остановите его (`Ctrl+C`), иначе будет ошибка `Conflict`.
> Токен можно взять из старого `.env`: `cp ../путь/к/старому/.env .env`.

Если Telegram недоступен напрямую — включите VPN или укажите прокси в `.env`: `PROXY_URL=socks5://127.0.0.1:1080`
(прокси применяется и к запросам к Open-Meteo).

## Ручной запуск

```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env      # вставьте токен от @BotFather
python bot.py
```

## Команды

| Команда | Что делает |
|---------|------------|
| `/add <текст>` или просто сообщение | Добавить задачу (приоритет `!1`, `!2`, `!3`) |
| `/list` | Активные задачи по приоритетам |
| `/today` | **Погода** + напоминания на сегодня + важные задачи |
| `/remind <номер> <ЧЧ:ММ>` / `<ДД.ММ ЧЧ:ММ>` | Напоминание (в тексте — краткая **погода**, если задан город) |
| `/unremind`, `/done`, `/completed`, `/delete`, `/priority` | Управление задачами |
| `/city <город>` | **Новое.** Задать город для погоды (поиск через геокодинг Open-Meteo) |
| `/weather` / `/weather <город>` | **Новое.** Погода сейчас и прогноз на день / для другого города |
| `/search <слово>` | **Новое.** Поиск по задачам (SQLite, без учёта регистра, кириллица) |
| `/week` | **Новое.** Задачи, созданные и выполненные за последние 7 дней |
| `/start`, `/help` | Приветствие и справка |

## Как это работает

- `weather.py` — запросы к Open-Meteo (геокодинг и прогноз), таймаут 15 с, кэш прогноза на 10 минут,
  форматирование и подсказки (зонт, холод, жара, ветер). Любая сетевая ошибка превращается в понятное сообщение.
- `bot.py` — команды Telegram, SQLite (таблицы `tasks`, `counters`, `users`), напоминания через JobQueue.
  Если погода недоступна, остальные функции работают как обычно.
- `test_logic.py` — автотесты (44 теста) на подставных ответах API: `python -m unittest -v test_logic`.
