# 📝 Бот-ассистент для задач — Лаб. 3 (деплой на Railway и обратная связь)

Telegram-бот: **@itmoftmi_krb_bot**. Версия из Лаб. 2 (задачи, напоминания, погода Open-Meteo, поиск) дополнена:

- **деплоем на Railway** — бот работает круглосуточно, без компьютера разработчика;
- **опросом `/feedback`** (оценка + 4 вопроса), отзывы хранятся в SQLite и пересылаются администратору;
- **статистикой для администратора** — `/stats` и `/feedbacks` (доступны только `ADMIN_ID`);
- устойчивостью: хранение базы на Volume, ограничение размера кэша, ошибки не роняют бота.

## Деплой на Railway (кратко)

1. Репозиторий на GitHub, в нём папка `lab3` (корень сервиса — `lab3`).
2. Railway → **New Project → Deploy from GitHub repo** → выбрать репозиторий.
3. Сервис → **Settings → Source → Root Directory** = `lab3`. Тип сервиса — worker (веб-порт не нужен), команда запуска берётся из `Procfile` / `railway.json`.
4. Сервис → **Variables**:

   | Переменная | Значение |
   |------------|----------|
   | `BOT_TOKEN` | токен от @BotFather |
   | `ADMIN_ID` | Telegram ID администратора |
   | `TIMEZONE` | `Europe/Moscow` |
   | `DB_PATH` | `/data/tasks.db` |

5. Сервис → **Volumes → Add Volume**, Mount path = `/data` (чтобы SQLite переживала перезапуски и новые деплои).
6. Дождаться статуса **Deployed** и строки в логах `Бот запущен`.

> ⚠️ Один токен — один запущенный бот. Перед деплоем остановите локальный бот (`Ctrl+C`), иначе будет ошибка `Conflict`.

## Локальный запуск (по-прежнему работает)

```bash
bash run.sh
```

## Команды

| Команда | Что делает |
|---------|------------|
| `/add <текст>` или просто сообщение | Добавить задачу (приоритет `!1`, `!2`, `!3`) |
| `/list`, `/today`, `/week`, `/search <слово>` | Просмотр и поиск задач |
| `/remind`, `/unremind`, `/done`, `/completed`, `/delete`, `/priority` | Управление задачами |
| `/city <город>`, `/weather` | Погода (Open-Meteo) |
| `/feedback` | **Новое.** Опрос: оценка 1–5 и 4 вопроса о боте |
| `/cancel` | **Новое.** Отменить опрос |
| `/stats` | **Новое, админ.** Пользователи, активность, популярные команды, средняя оценка |
| `/feedbacks` | **Новое, админ.** Последние отзывы |
| `/start`, `/help` | Приветствие и справка |
