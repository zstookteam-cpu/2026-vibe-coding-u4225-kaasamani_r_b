# 📝 Бот-ассистент для задач

## Быстрый запуск (macOS / Linux)

```bash
bash run.sh
```

Скрипт создаст виртуальное окружение, установит зависимости, спросит токен бота (он сохранится в `.env`) и запустит бота.
Если Telegram недоступен напрямую, включите VPN или укажите прокси в `.env`: `PROXY_URL=socks5://127.0.0.1:1080`.

---

Telegram-бот на Python (`python-telegram-bot`): принимает задачи, расставляет приоритеты, присылает напоминания. У каждого пользователя свой список задач. Данные хранятся в SQLite (`tasks.db`).

## Возможности

- Любое сообщение (не команда) или `/add <текст>` создаёт задачу
- Приоритет тегом в тексте: `!1` 🔴 высокий, `!2` 🟡 средний, `!3` 🟢 низкий (без тега — средний)
- Номера задач постоянные — не меняются после удаления других задач
- Напоминания, которые переживают перезапуск бота

## Команды

| Команда | Что делает | Пример |
|---|---|---|
| `/start` | Приветствие | |
| `/help` | Список команд | |
| `/add <текст>` | Добавить задачу | `/add Купить молоко !1` |
| `/list` | Активные задачи по приоритетам | |
| `/today` | Напоминания на сегодня + все задачи высокого приоритета | |
| `/done <номер>` | Отметить выполненной | `/done 3` |
| `/completed` | Последние 10 выполненных | |
| `/delete <номер>` | Удалить задачу | `/delete 3` |
| `/priority <номер> <1\|2\|3>` | Сменить приоритет | `/priority 3 1` |
| `/remind <номер> <ЧЧ:ММ>` | Напомнить сегодня (если время прошло — завтра) | `/remind 3 18:30` |
| `/remind <номер> <ДД.ММ ЧЧ:ММ>` | Напомнить в указанную дату | `/remind 3 25.12 09:00` |
| `/unremind <номер>` | Отменить напоминание | `/unremind 3` |

## Запуск

### 1. Получите токен бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, задайте имя и username бота.
3. Скопируйте выданный токен.

### 2. Установите Python

Нужен Python 3.9 или новее (`python --version`).

### 3. Подготовьте проект

```bash
# перейдите в папку с проектом
cd путь/к/папке/с/ботом

# создайте виртуальное окружение
python -m venv venv

# активируйте его
# Linux / macOS:
source venv/bin/activate
# Windows (PowerShell):
venv\Scripts\Activate.ps1

# установите зависимости
pip install -r requirements.txt
```

### 4. Настройте `.env`

```bash
# Linux / macOS:
cp .env.example .env
# Windows:
copy .env.example .env
```

Откройте `.env` и впишите токен:

```
BOT_TOKEN=ваш_токен_от_BotFather
TIMEZONE=Europe/Moscow
```

`TIMEZONE` — название часового пояса из [списка tz database](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones) (например, `Europe/Moscow`, `Asia/Yekaterinburg`). Если не указать — используется `Europe/Moscow`.

### 5. Запустите бота

```bash
python bot.py
```

В консоли появится сообщение «Бот запущен». Откройте бота в Telegram и отправьте `/start`. Остановка — `Ctrl+C`.

## Как это устроено

- `bot.py` — весь код бота (с комментариями).
- `tasks.db` — файл базы SQLite, создаётся автоматически при первом запуске.
- Напоминания хранятся в базе и планируются через `JobQueue`. При перезапуске бот заново планирует все неотправленные напоминания; если время уже прошло, пока бот был выключен, напоминание придёт сразу с пометкой.

## Частые проблемы

- **«Не задан BOT_TOKEN»** — проверьте, что файл называется именно `.env` и лежит рядом с `bot.py`.
- **Ошибка про `JobQueue`** — установите зависимости именно через `pip install -r requirements.txt` (нужен extra `[job-queue]`).
- **Неизвестный часовой пояс** — проверьте написание `TIMEZONE` (регистр важен: `Europe/Moscow`).
- **Бот не отвечает** — убедитесь, что скрипт запущен и токен верный; смотрите логи в консоли.
