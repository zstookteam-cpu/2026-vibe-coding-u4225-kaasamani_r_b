# Промпты для LLM (Лаб. 1, вариант 3 — бот-ассистент для задач)

Использована LLM: Claude. Промпт составлен по шаблону из задания Лаб. 1.

## Исходный промпт

```
Создай Telegram-бота на Python с использованием библиотеки python-telegram-bot.

Функционал бота («Бот-ассистент для задач»):
- Принимает задачи в текстовом виде: любое обычное сообщение (не команда) или команда /add <текст> создаёт новую задачу.
- Приоритет задаётся тегом в тексте: !1 (высокий), !2 (средний), !3 (низкий). Без тега приоритет средний. Тег не входит в текст задачи.
- Организует задачи по приоритетам: /list показывает активные задачи, сгруппированные по приоритету (🔴 высокий, 🟡 средний, 🟢 низкий). У каждой задачи свой номер, который не меняется после удаления других задач.
- Напоминания: /remind <номер> <ЧЧ:ММ> (сегодня, а если время уже прошло — завтра) или /remind <номер> <ДД.ММ ЧЧ:ММ>. В указанное время бот присылает напоминание с текстом задачи. /unremind <номер> отменяет напоминание.
- Списки дел: /today показывает задачи с напоминанием на сегодня и все задачи высокого приоритета; /done <номер> отмечает задачу выполненной; /completed показывает последние 10 выполненных; /delete <номер> удаляет задачу; /priority <номер> <1|2|3> меняет приоритет.
- /start — приветствие, /help — список команд с примерами.
- Ответы на русском языке, краткие, с эмодзи.
- Данные: у каждого пользователя свой список задач.

Требования:
- Бот должен быть простым и понятным.
- Код должен быть хорошо прокомментирован (комментарии на русском).
- Использовать SQLite для хранения данных (файл tasks.db).
- Добавить обработку ошибок: неверный номер задачи, неверный формат времени, пустой текст, время в прошлом. Бот отвечает понятным сообщением и не падает.
- Токен бота читать из переменной окружения BOT_TOKEN (файл .env, python-dotenv), в коде токена быть не должно.
- Напоминания реализовать через JobQueue; при перезапуске бота восстанавливать неотправленные напоминания из базы.
- Часовой пояс брать из переменной TIMEZONE в .env (по умолчанию Europe/Moscow).
- Добавить логирование в консоль.

Создай:

1. Файл bot.py с кодом бота
2. Файл requirements.txt с зависимостями (с указанием версий)
3. Файл README.md с пошаговой инструкцией по запуску
4. Файл .env.example для примера конфигурации
5. Файл .gitignore (в нём .env, tasks.db, __pycache__, *.pyc)
```

Результат: LLM сгенерировала `bot.py` (около 600 строк), `requirements.txt`, `README.md`, `.env.example`, `.gitignore`.

## Итерации и улучшения

### Итерация 1 — запуск на macOS
**Проблема.** При запуске на MacBook команды `pip` и `python` не найдены (в системе есть только `python3`);
файлы скачались без точки в имени (`env`, `gitignore`), токен не был задан.

**Запрос к LLM (по смыслу):** «Не получается запустить. Вот файлы, которые получились — сделай запуск за меня».

**Результат.** Добавлен скрипт `run.sh`: создаёт виртуальное окружение, устанавливает зависимости через
`python -m pip`, при отсутствии токена запрашивает его скрытым вводом и записывает в `.env`, затем запускает бота.

### Итерация 2 — таймаут соединения с Telegram
**Проблема.** Бот запускался, но падал на первом запросе к Telegram:
`telegram.error.TimedOut` (`httpx.ReadTimeout`) — сеть не пропускала или сильно задерживала соединение с `api.telegram.org`.

**Запрос к LLM (по смыслу):** текст ошибки целиком (traceback) приложен к сообщению.

**Результат.**
- Таймауты соединения увеличены до 30 секунд (40 секунд — для получения обновлений).
- Добавлена необязательная переменная `PROXY_URL` в `.env` (поддержка HTTP- и SOCKS-прокси);
  в `requirements.txt` добавлена зависимость `httpx[socks]`.
- Дополнительно рекомендовано включить VPN. После этого бот подключился и ответил на `/start`.
